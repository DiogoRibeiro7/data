# Migration audit: `Medium-Blog` data

## Scope

Source repository: `DiogoRibeiro7/Medium-Blog`

The default branch contains **41 CSV paths**. Of these, 39 are Git LFS pointers and two are small directly committed publication snapshots.

The audit applies the central data repository policy: reusable upstream datasets should be represented centrally only when provenance and redistribution terms are clear; project-specific generated/derived artifacts remain with the article that creates them.

## Decision

No Medium-Blog CSV bytes are copied directly into the canonical `datasets/` registry in this migration.

Instead, three reusable upstream sources are registered under `external/`:

- `external/online-retail-ii/`
- `external/world-bank-greenhouse-gas/`
- `external/berkeley-earth-temperature/`

This is deliberate:

- UCI Online Retail II is openly licensed, but the Medium files are sheet extracts/derived copies and the authoritative UCI workbook is the better source.
- The World Bank indicator is openly licensed, while the Medium repository also contains a locally derived reshaped output.
- Berkeley Earth data is reusable under its stated non-commercial terms, but the exact lineage of the older CSV snapshots in Medium-Blog is not documented well enough to republish them as canonical snapshots.
- Walmart competition files are subject to competition rules.
- Telco churn is explicitly documented in the Medium code as a Kaggle download for which users should ensure they have permission.
- several other historical files have unresolved provenance.

## Open-source records centralized

### UCI Online Retail II

The Medium notebook reads `online_retail_II.xlsx`, and the large retail CSV files are extracts/copies derived from that source.

The authoritative UCI dataset currently states **CC BY 4.0** and provides DOI `10.24432/C5CG6D`. The central data repository records the authoritative source rather than duplicating the article-specific extracts.

### World Bank greenhouse-gas indicator

The Medium climate notebook reads World Bank indicator export `EN.ATM.GHGT.KT.CE` and later writes `total-ghg-emissions.csv`.

World Bank open-data terms default World Bank-produced datasets to **CC BY 4.0** unless dataset-specific metadata states otherwise. The source indicator is therefore registered centrally; the reshaped article output stays with the article.

### Berkeley Earth temperature data

The historical climate CSV filenames correspond to Berkeley Earth-style land-temperature products. Berkeley Earth's current data page states that its data is generally licensed under **CC BY-NC 4.0**.

Because the Medium repository does not document the exact download snapshot and chain of custody, the central repository records Berkeley Earth as the upstream source but does not republish those LFS objects.

## Medium-Blog changes

No notebook or script path is changed by this audit because no data bytes move out of `Medium-Blog`. This preserves reproducibility of historical articles.

Duplicate cleanup inside `Medium-Blog` should be a separate maintenance change after checking every consumer; it is not required for central-data migration.

## Result

The central repository gains reusable provenance/source records while avoiding:

- duplicating Git LFS objects;
- republishing competition-restricted data;
- promoting generated article artifacts into canonical datasets;
- pretending unresolved historical provenance is known.
